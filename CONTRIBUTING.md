# Contributing

Issues and pull requests are welcome.

- **Bugs**: open an issue with the exact call you made, what you expected, and what you got. Never include your real API key.
- **Features**: open an issue first so we can discuss the shape before you write code.
- **Pull requests**: keep them focused (one change per PR), match the existing code style, and make sure examples still run.
- **Questions about the API itself**: see the docs at https://api.halalterminal.com/docs or email yassir@halalterminal.com.

Be respectful. That is the whole code of conduct.
